# 第6章 フロントエンド：画面を作る

**この章から、自分だけのリポジトリで作業を始めます。**コードは自分のリポジトリに、手順書はこれまでどおりこのリポジトリ（https://github.com/Muby1/webapp-course-docs ）に置いてあります。この2つを行き来しながら進めてください。

## この章のゴール

ダミーデータのタスク一覧を画面に表示し、追加・完了切り替え・削除を画面上で動かせるようになります。

## 6-1 受講者用テンプレートから自分のリポジトリを作る

### やること

講師が用意したテンプレートから、自分だけのコード置き場（リポジトリ）を作ります。

### 操作

1. テンプレートリポジトリ（https://github.com/Muby1/webapp-course-template ）を開く
2. 「Use this template」ボタンをクリックする
3. 「Include all branches」に**必ずチェックを入れる**（章が進むごとに使う、章ごとの区切りのブランチも一緒にコピーするため）
4. リポジトリ名を決める（例：`kantan-task`）
5. 「Public」（公開）を選ぶ
6. 「Create repository」をクリックする

### うまくいったときの結果

自分のGitHubアカウントの下に、テンプレートと同じ内容の新しいリポジトリができる。

［スクショ ch06-1：「Use this template」の作成画面（Include all branchesのチェック含む）］

### うまくいかないとき

- 「Fork」ボタンと間違えないよう注意する（「Use this template」を使う）
- 誤って「Private」で作ってしまった場合、リポジトリの「Settings」から「Public」に変更できる

## 6-4 ダミーデータの配列を一覧表示する関数を完成させる

### やること

`public/script.js`を開くと、ファイルの上の方に、あらかじめダミーのタスクが入った配列があります。

```js
let taskList = [
  { id: 1, title: '牛乳を買う', done: false },
  { id: 2, title: '掃除をする', done: true }
];
```

`renderTaskList`という関数の中に、次のような印が付いた部分があります。この`@@TODO-START`と`@@TODO-END`の間に、`taskList`配列の中身を1つずつ画面に表示するコードを書きます。

### コード

```js
function renderTaskList() {
  // @@TODO-START id=ch06-1 hint="手順書 6-4 を参考に、taskList配列の中身をひとつずつ画面に表示しましょう"
  taskListElement.textContent = '';
  for (const task of taskList) {
    const taskElement = createTaskElement(task);
    taskListElement.appendChild(taskElement);
  }
  // @@TODO-END
}
```

`createTaskElement`という、1件分の行（チェックボックス・タイトル・削除ボタン）を作る関数は、すぐ下にすでに用意されています。`taskListElement.textContent = '';`で一度画面を空にしてから、`for...of`で配列を1つずつ取り出し、`appendChild`で画面に追加していきます。

### うまくいったときの結果

ブラウザを再読み込みすると、「牛乳を買う」「掃除をする」の2件がタスク一覧に表示される。

### うまくいかないとき

- 何も表示されない場合、保存できているか、ブラウザを再読み込みしたか確認する

## 6-5 追加ボタンでタスクを追加する

### やること

`handleAddClick`関数のTODOを埋め、入力欄の内容を新しいタスクとして追加できるようにします。

### コード

```js
function handleAddClick() {
  // @@TODO-START id=ch06-2 hint="手順書 6-5 を参考に、入力欄の値を新しいタスクとしてtaskList配列に追加しましょう"
  const title = taskTitleInput.value.trim();
  if (title === '') {
    return;
  }
  const newTask = { id: nextTaskId, title: title, done: false };
  taskList.push(newTask);
  nextTaskId = nextTaskId + 1;
  taskTitleInput.value = '';
  renderTaskList();
  // @@TODO-END
}
```

`nextTaskId`は、ファイルの上の方で`let nextTaskId = 3;`と用意されている変数で、新しいタスクに次の番号を割り振るために使います。最後に`renderTaskList()`を呼び直すことで、画面が最新の状態に更新されます。

### うまくいったときの結果

入力欄に文字を入れて追加ボタンを押すと、一覧に新しい行が増える。空欄のまま追加ボタンを押しても、何も増えない。

### うまくいかないとき

- 追加されない場合、`taskList.push(newTask)`の`newTask`の綴りを確認する
- 空欄でも追加されてしまう場合、`if (title === '')`の判定を確認する

## 6-6 チェックボックスで完了状態を切り替える

### やること

`handleToggleClick`関数のTODOを埋めます。

### コード

```js
function handleToggleClick(event) {
  // @@TODO-START id=ch06-3 hint="手順書 6-6 を参考に、クリックされたタスクのdoneを反転させましょう"
  const taskId = Number(event.target.dataset.taskId);
  for (const task of taskList) {
    if (task.id === taskId) {
      task.done = !task.done;
    }
  }
  renderTaskList();
  // @@TODO-END
}
```

`event.target`は「実際にクリックされた要素」（このチェックボックス自身）を指します。`createTaskElement`の中で`checkbox.dataset.taskId = String(task.id);`としてタスクのidを要素に貼り付けてあるので、`event.target.dataset.taskId`でどのタスクがクリックされたかが分かります。`!task.done`は、第3章で扱った否定（`!`）で、`true`と`false`を反転させています。

### うまくいったときの結果

チェックボックスを押すと、タイトルに取り消し線が付く（`done`が`true`のときのスタイル）。もう一度押すと元に戻る。

### うまくいかないとき

- 反応しない場合、`event.target.dataset.taskId`の綴りを確認する

## 6-7 削除ボタンでタスクを削除する

### やること

`handleDeleteClick`関数のTODOを埋めます。

### コード

```js
function handleDeleteClick(event) {
  // @@TODO-START id=ch06-4 hint="手順書 6-7 を参考に、押されたタスクをtaskList配列から取り除きましょう"
  const taskId = Number(event.target.dataset.taskId);
  const remainingTasks = [];
  for (const task of taskList) {
    if (task.id !== taskId) {
      remainingTasks.push(task);
    }
  }
  taskList = remainingTasks;
  renderTaskList();
  // @@TODO-END
}
```

削除したいタスク**以外**を新しい配列（`remainingTasks`）に集め直し、それを新しい`taskList`とする、という考え方です。

### うまくいったときの結果

削除ボタンを押すと、その行が一覧から消える。

### うまくいかないとき

- 消えない場合、`!==`（等しくない）と`===`（等しい）を書き間違えていないか確認する
