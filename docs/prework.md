# 事前課題

講座が始まる前に、自分のパソコンで準備しておくことが5つあります。順番にやってください。全部で30分〜1時間くらいかかります。

準備が終わったら、いちばん下の「提出すること」を読んで提出してください。

## 事前-1 GitHubのアカウントを作る

### やること

GitHub（ギットハブ）という、プログラムを保存しておくためのWebサービスのアカウントを作ります。この講座で書いたコードは、すべてGitHubに置くことになります。

### 操作

1. https://github.com/ を開く
2. 「Sign up」をクリックする
3. メールアドレス・パスワード・ユーザー名を入力して進める（ユーザー名は他の人にも見えるので、実名でなくてよい）
4. 表示される確認コードなどを入力し、アカウントを作成する

### うまくいったときの結果

GitHubにログインした状態で、自分のユーザー名がページの右上に表示される。

［スクショ prework-1：GitHubアカウント作成画面（サインアップフォーム）］

### うまくいかないとき

- メールが届かない場合は、迷惑メールフォルダも確認する → うまくいかない場合は `faq.md` の「GitHubの確認メールが届かない」を見る

---

## 事前-2 Renderのアカウントを作る

### やること

Render（レンダー）という、これから作るアプリを公開するためのWebサービスのアカウントを作ります。GitHubのアカウントでログインします。

### 操作

1. https://render.com/ を開く
2. 「Get Started」または「Sign Up」をクリックする
3. 「GitHub」でログインする
4. GitHubとの連携を許可する画面が出たら「Authorize Render」をクリックする

### うまくいったときの結果

Renderのダッシュボード画面が表示される。

［スクショ prework-5：Renderの「Sign up with GitHub」ボタン画面］

### うまくいかないとき

- GitHubでログインする画面が出ない場合は、事前-1が完了しているか確認する

---

## 事前-3 Neonのアカウントを作る

### やること

Neon（ネオン）という、データを保存しておくためのWebサービスのアカウントを作ります。こちらもGitHubのアカウントでログインします。

### 操作

1. https://neon.tech/ を開く
2. 「Sign Up」をクリックする
3. 「Continue with GitHub」を選ぶ
4. GitHubとの連携を許可する画面が出たら許可する

### うまくいったときの結果

Neonのダッシュボード画面が表示される（初めてのプロジェクト作成を促す画面が出ることがあるが、まだ何も作らなくてよい）。

### うまくいかないとき

- 同上（事前-1が完了しているか確認する）

---

## 事前-4 Node.jsをインストールする

### やること

Node.js（ノード・ジェイエス）という、JavaScriptというプログラムをパソコン上で動かすためのソフトをインストールします。バージョンは講師が指定する24系を入れてください。

### 操作

1. https://nodejs.org/ を開く
2. 案内されたバージョン（24系）のWindows用インストーラーをダウンロードする
3. ダウンロードしたファイルを実行し、基本的には「Next」を押して既定のまま進める

［スクショ prework-4：Node.jsインストーラー画面］

### うまくいったときの結果

インストーラーが「Finish」まで進み、エラーが出ない。

### うまくいかないとき

- すでに古いバージョンのNode.jsが入っている場合は、先に「アプリと機能」からアンインストールしてから入れ直す → `faq.md` の「Node.jsのバージョンが違う」を見る

---

## 事前-5 Git for Windowsをインストールする

### やること

Git（ギット）という、コードの変更履歴を管理するソフトをインストールします。**途中で改行コードの設定を選ぶ画面が出ます。設定を変えず、既定のまま進めてください**（この設定の意味は第5章で説明します）。

### 操作

1. https://git-scm.com/download/win を開き、64-bit版のインストーラーをダウンロードする
2. インストーラーを実行し、基本的には「Next」を押して既定のまま進める
3. 「Configuring the line ending conversions」という画面が出たら、**「Checkout Windows-style, commit Unix-style line endings」（既定で選ばれているもの）のまま**「Next」を押す

［スクショ prework-3：Git for Windowsインストーラーの改行コード設定画面（クリックする場所は無く、既定のままにする箇所を枠で示す）］

4. 最後まで進めて「Install」→「Finish」

### うまくいったときの結果

インストーラーが「Finish」まで進み、エラーが出ない。

### うまくいかないとき

- 途中の画面で何を選べばよいか分からなくなった場合は、基本的にすべて既定（最初から選ばれているもの）のままで進めて問題ない → `faq.md` の「Gitのインストール画面で迷ったとき」を見る

---

## 事前-6 VS Codeをインストールする

### やること

VS Code（ブイエスコード）という、これからずっと使うエディタ（プログラムを書くためのソフト）をインストールします。細かい設定は第2章で行うので、ここではインストールだけでよいです。

### 操作

1. https://code.visualstudio.com/ を開く
2. Windows用のインストーラーをダウンロードする
3. インストーラーを実行し、既定のまま進める（「デスクトップにアイコンを作成する」にチェックを入れておくと起動しやすい）

### うまくいったときの結果

VS Codeが起動し、画面が表示される。

---

## 事前-7 バージョンを確認する

### やること

事前-4〜事前-6でインストールしたものが、それぞれ正しく使える状態になっているかを確認します。

### コマンド

1. VS Codeを開き、メニューの「Terminal」→「New Terminal」でターミナルを開く（PowerShellという画面が下に出る）
2. 次の3つを1行ずつ入力してEnterを押す

```
node -v
npm -v
git --version
```

### うまくいったときの結果

それぞれ次のようにバージョンの数字が表示される（数字の細かい部分は違っていてよい。`node -v`の最初が`v24`になっていることだけ確認する）。

```
v24.x.x
10.x.x
git version 2.x.x.windows.x
```

［スクショ prework-2：ターミナルでの3つのバージョン確認結果（1枚にまとめてよい）］

### うまくいかないとき

- 「'node' は、内部コマンドまたは外部コマンド、操作可能なプログラムまたはバッチ ファイルとして認識されていません。」と表示される場合、VS Codeとターミナルを再起動する（それでも直らなければパソコン自体を再起動する）→ `faq.md` の「'node' や 'git' が認識されないと言われる」を見る
