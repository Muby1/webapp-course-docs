# 第1章 Webの仕組み

## この章のゴール

URLを開いてからページが表示されるまでの流れを、たとえ話で説明できるようになります。この章では何もインストールしたり書いたりしません。

## 1-1 身近なサイトのURLを分解してみる

### やること

普段見ているWebサイトのURLが、いくつかの部分でできていることを確認します。

### 操作

ブラウザのアドレスバーに表示されているURLを見て、次の3つに分けてみてください。

```
https://www.example.com/about
├─┬──┘ └──────┬───────┘└──┬──┘
 │           │          │
 │       ドメイン       パス
 │     （どのサーバーか）（サーバーの中のどこか）
「https://」
（通信の方法。HTTPという約束ごとを、
 安全な形（Sで暗号化）で使うという意味）
```

3〜4個のサイトのURLで、同じように分解してみましょう。

### うまくいったときの結果

「ドメイン」と「パス」がどこを指すか、隣の人に説明できる。

### 考えてみよう

「https://」の代わりに「http://」（Sが無い）と表示されるサイトもあります。何が違うと思いますか。

## 1-2 「ページのソースを表示」でHTMLを見てみる

### やること

Webページの「正体」が、HTMLという文字だけのファイルであることを確認します。

### 操作

1. 適当なWebページを開く
2. ページ上で右クリックし、「ページのソースを表示」を選ぶ（ブラウザによってメニューの名前が多少異なります）

### うまくいったときの結果

見た目のきれいなページの裏側に、`<`と`>`で囲まれた文字（タグ）がたくさん並んだ画面が表示される。

### 考えてみよう

普段見ているカラフルなページと、今見えている文字だらけの画面は、同じものです。ブラウザは、このHTMLというテキストを読み取って、見た目を組み立てて表示しています。この後の章（第2章）で、自分でもこのHTMLを書いていきます。
