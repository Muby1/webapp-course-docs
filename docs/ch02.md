# 第2章 はじめてのHTML

## この章のゴール

VS CodeでHTMLファイルを作り、ブラウザで表示して、書き換えた結果を確認できるようになります。

## 2-1 拡張子を表示する設定にする

### やること

Windowsは初期設定では、ファイル名の後ろに付く`.html`のような「拡張子」を表示しません。表示されるように設定を変えます。拡張子が見えないと、後の手順で作るファイルが正しい種類になっているか確認できません。

### 操作

1. エクスプローラー（フォルダの画面）を開く
2. 上部のメニューから「表示」→「表示」→「ファイル名拡張子」にチェックを入れる（Windowsのバージョンによってメニューの位置が多少異なります）

### うまくいったときの結果

エクスプローラーで、ファイル名の後ろに`.txt`や`.html`のような文字が表示されるようになる。

### うまくいかないとき

- メニューの場所が見つからない場合、Windowsのバージョンを確認し、「ファイル名拡張子 表示」で検索する → `faq.md`の「拡張子が表示されない」を見る

---

## 2-2 作業フォルダを作る

### やること

これから作るファイルを置いておく、専用のフォルダを作ります。

### 操作

1. `C:\dev` というフォルダを作る（`C:`ドライブの直下）
2. その中に `C:\dev\my-profile` というフォルダを作る

**注意**：フォルダの場所には、次の3つを避けてください。

- 日本語を含む場所（例：`C:\ユーザー\デスクトップ`）
- 空白を含む場所
- `OneDrive`の中（自動で同期される場所は、後の章で使うツールと相性が悪いことがあります）

### うまくいったときの結果

`C:\dev\my-profile` フォルダが存在する。

### うまくいかないとき

- 上の3つのどれかに当てはまる場所に作ってしまった場合、`C:\dev`を作り直す → `faq.md`の「作業フォルダの場所を間違えた」を見る

---

## 2-3 VS Codeの初期設定をする

### やること

VS Codeを、これから使いやすいように設定します。

### 操作

1. VS Codeを開き、左側の四角が4つ並んだアイコン（拡張機能）をクリックする
2. 「Japanese Language Pack」を検索してインストールし、案内に従って再起動する（日本語化）
3. 全角スペース（見た目は半角スペースと似ているが別の文字）を目立たせるため、「zenkaku」という拡張機能を検索してインストールする
4. 自動保存を有効にする：メニューの「File」（日本語化後は「ファイル」）→「Auto Save」（自動保存）をクリックしてチェックを付ける

### うまくいったときの結果

- メニューが日本語で表示される
- 全角スペースを含む文字を入力すると、色が付くなどして目立つ
- ファイルを編集すると、保存ボタンを押さなくても少し待つと自動的に保存される（タブのファイル名の横にある●印が消える）

### うまくいかないとき

- 拡張機能が検索しても出てこない場合、インターネット接続を確認する

## 2-4 `index.html`を作り、ブラウザで表示する

### やること

HTMLファイルを1つ作り、ブラウザで開いてみます。

### コード

VS Codeで`C:\dev\my-profile`フォルダを開き（「File」→「Open Folder」）、`index.html`という名前のファイルを新規作成して、次の内容を書いて保存する。

```html
<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>自己紹介</title>
</head>
<body>
  <h1>ここに名前が入ります</h1>
</body>
</html>
```

### うまくいったときの結果

エクスプローラーで`index.html`をダブルクリックすると、ブラウザが開き、「ここに名前が入ります」という大きな文字が表示される。

### うまくいかないとき

- ファイルが`index.html.txt`という名前になっている（拡張子が二重になっている）場合、2-1の設定ができているか確認し、ファイル名を`index.html`に直す → `faq.md`の「index.html.txtになっている」を見る
- 保存したのに表示が変わらない場合、ブラウザで再読み込み（`F5`キー）する → `faq.md`の「保存したのに変わらない」を見る

## 2-5 見出し・段落・リスト・画像・リンクを追加する

### やること

HTMLの基本的な部品（タグ）を追加していきます。「タグ」は`<h1>`のような印で、開始と終了（`</h1>`）で挟んだ部分が1つの「要素」になります。

### コード

`<body>`の中身を、次のように書き換える。

```html
<body>
  <h1>山田太郎</h1>
  <p>プログラミングを勉強中です。よろしくお願いします。</p>

  <h2>好きなこと</h2>
  <ul>
    <li>読書</li>
    <li>散歩</li>
    <li>料理</li>
  </ul>

  <img src="https://via.placeholder.com/150" alt="自分の写真（仮）">

  <p><a href="https://github.com/">GitHubを見る</a></p>
</body>
```

`<img>`タグの`src`や`<a>`タグの`href`のように、タグの中に書く追加情報を「属性」と呼びます。

### うまくいったときの結果

見出し・文章・箇条書き・画像・リンクが、上から順にブラウザに表示される。リンクをクリックすると、指定したページが開く。

### うまくいかないとき

- 閉じタグ（`</li>`など）を書き忘れると、表示が崩れることがある → `faq.md`の「HTMLの表示が崩れる」を見る

### 改造してみよう

`<img>`タグの`src`を、自分が使ってよい画像のURLに変えてみましょう。

## 2-6 CSSで見た目を変える

### やること

CSS（見た目を決める言語）を使って、文字の色や大きさを変えます。CSSは「セレクタ（どの要素に）」と「プロパティ（何を、どう変えるか）」の組み合わせで書きます。

### コード

`<head>`の中、`</head>`より前に追加する。

```html
<style>
  h1 {
    color: darkblue;
    font-size: 32px;
  }
  li {
    color: green;
  }
</style>
```

`h1`がセレクタ（`<h1>`要素を選ぶ）、`color`と`font-size`がプロパティです。

### うまくいったときの結果

見出しが紺色で大きく表示され、箇条書きの文字が緑色になる。

### うまくいかないとき

- 色や大きさが変わらない場合、`{`と`}`の対応、`;`（セミコロン）の付け忘れを確認する

### 改造してみよう

好きな色・文字の大きさに変えてみましょう。他の要素（`p`や`body`など）にもスタイルを付けてみてください。

## 2-7 自己紹介ページを完成させる

### やること

ここまでの内容を組み合わせて、自分だけの自己紹介ページを完成させます。

### 作る内容

- 自分の名前（見出し）
- 自己紹介の文章（段落）
- 好きなもの・趣味（箇条書き、3つ以上）
- 画像（自分の使ってよい画像、またはプレースホルダー画像）
- リンク（好きなサイトなど）
- CSSで、少なくとも2つの要素の見た目を変える

### うまくいったときの結果

自分で決めた内容が、自分で決めた見た目でブラウザに表示される。
