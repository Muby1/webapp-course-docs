## 3-1 コンソールに文字を表示する

### やること

`console.log()`という命令を使うと、ブラウザの「開発者ツール」の中にある「コンソール」という画面に文字を表示できます。プログラムの動きを確認するときによく使います。

### コード

`<script>`タグの中に、次の1行を書く。

```html
<script>
  console.log('こんにちは');
</script>
```

### うまくいったときの結果

1. `index.html`を保存する
2. ブラウザで開く（すでに開いていれば再読み込み）
3. キーボードの`F12`キーを押して開発者ツールを開き、「Console」タブを選ぶ
4. 「こんにちは」という文字が表示されている

［スクショ ch03-1：コンソールに「こんにちは」と表示された画面］

### うまくいかないとき

- 何も表示されない場合、`<script>`タグの位置や、綴りの間違い（`console`のスペルなど）を確認する → `faq.md`の「consoleに何も表示されない」を見る

## 3-2 変数・計算・条件分岐

### やること

「変数」は、値に名前を付けて覚えておくための仕組みです。`let`と`const`という2つの書き方があります。値を後で変える予定がなければ`const`、変える予定があれば`let`を使います。

条件分岐（`if`）を使うと、「もし〜なら、こうする」という処理が書けます。あわせて、`!`（否定）・`||`（または）・`!==`（等しくないか）・`.trim()`（前後の空白を取り除く）も使ってみます。

### コード

`console.log('こんにちは');`の下に、続けて書く。

```js
const age = 20;
if (age >= 20) {
  console.log('大人です');
} else {
  console.log('子どもです');
}

const nameWithSpaces = '  たろう  ';
const trimmedName = nameWithSpaces.trim();
console.log(trimmedName);

const isRaining = false;
if (!isRaining) {
  console.log('傘は要りません');
}

const favoriteColor = 'あか';
if (favoriteColor === 'あか' || favoriteColor === 'あお') {
  console.log('好きな色です');
}

const score = 80;
if (score !== 100) {
  console.log('満点ではありません');
}
```

### うまくいったときの結果

コンソールに次の5行が順番に表示される。

```
大人です
たろう
傘は要りません
好きな色です
満点ではありません
```

### うまくいかないとき

- `=`（代入）と`===`（比較）を間違えると、意図しない動きになる → `faq.md`の「=と===を間違えた」を見る

### 改造してみよう

`age`の値を`10`に変えて保存し直し、表示が「子どもです」に変わることを確認してください。

## 3-3 配列と繰り返し

### やること

「配列」は、複数の値をひとつにまとめて並べておく仕組みです。`for...of`という書き方を使うと、配列の中身を順番に1つずつ取り出せます。配列の`.length`で、中身が何個あるかを調べられます。

### コード

```js
const foods = ['ラーメン', 'カレー', '寿司'];
console.log('好きな食べ物は' + foods.length + '個あります');

for (const food of foods) {
  console.log(food);
}
```

### うまくいったときの結果

```
好きな食べ物は3個あります
ラーメン
カレー
寿司
```

### うまくいかないとき

- 表示される数と配列の中身の数が合わない場合、配列を作るときの`,`（カンマ）の付け忘れ・付けすぎを確認する

### 改造してみよう

自分の好きな食べ物3つに書き換えて、同じように表示されることを確認してください。

## 3-4 オブジェクト

### やること

「オブジェクト」は、名前（キー）と値の組をまとめておく仕組みです。配列が「順番に並んだ箱」だとすると、オブジェクトは「ラベルの付いた箱」です。

### コード

```js
const profile = {
  name: 'たろう',
  age: 20,
  hobby: '読書'
};

console.log(profile.name);
console.log(profile.age);
console.log(profile.hobby);
```

### うまくいったときの結果

```
たろう
20
読書
```

### うまくいかないとき

- `profile.name`が`undefined`と表示される場合、オブジェクトのキー名（`name`など）と、取り出すときの書き方が一致しているか確認する

### 改造してみよう

自分のプロフィール（名前・年齢・趣味）に書き換えてください。項目をもう1つ（好きな食べ物など）追加してみましょう。

## 3-5 関数

### やること

「関数」は、決まった処理をひとまとめにして、名前を付けておく仕組みです。関数に渡す値を「引数」、関数から返ってくる値を「戻り値」と呼びます。

### コード

```js
function calculateTaxIncludedPrice(price) {
  const taxIncludedPrice = price * 1.1;
  return taxIncludedPrice;
}

const result = calculateTaxIncludedPrice(1000);
console.log(result);
```

### うまくいったときの結果

```
1100
```

### うまくいかないとき

- `return`を書き忘れると、`result`が`undefined`になる → `faq.md`の「関数の戻り値がundefinedになる」を見る

### 改造してみよう

`calculateTaxIncludedPrice`を、別の金額（例：`500`）で呼び出してみてください。

## 3-6 ボタンを押すと文字が変わる（DOMとイベント）

### やること

ここまではコンソールに表示するだけでしたが、ここからは画面そのものを変えます。「DOM」は、HTMLの要素をJavaScriptから操作するための仕組みです。`document.getElementById`でHTMLの要素を取得し、`textContent`で表示内容を書き換えます。ボタンが押されたときに関数を実行するには、「イベント」（`addEventListener`）を使います。

### コード

`<body>`の中、`<script>`より前に次を追加する。

```html
<button id="greetButton" type="button">押してね</button>
<p id="messageText"></p>
```

`<script>`の中に追加する。

```js
const greetButton = document.getElementById('greetButton');
const messageText = document.getElementById('messageText');

function handleGreetButtonClick() {
  messageText.textContent = 'こんにちは！';
}

greetButton.addEventListener('click', handleGreetButtonClick);
```

### うまくいったときの結果

ボタンを押すと、その下に「こんにちは！」と表示される。

［スクショ ch03-4：ボタンを押す前と押した後の画面（比較できるよう2枚並べる）］

### うまくいかないとき

- ボタンを押しても何も起きない場合、`id`の綴りが`getElementById`の中の文字列と一致しているか確認する → `faq.md`の「ボタンを押しても反応しない」を見る

### 改造してみよう

表示する文字を自分の好きな言葉に変えてみましょう。ボタンを押すたびに違う言葉が出るようにできるでしょうか（ヒントは3-7で扱います）。

## 3-7 ミニ課題：おみくじボタン

### やること

ボタンを押すと、「大吉」「吉」「凶」のどれかがランダムに表示される「おみくじ」を自分で作ってください。ここまでの書き方をすべて組み合わせます。

### ヒント

- 3つの結果を配列に入れておきます：`const omikujiResults = ['大吉', '吉', '凶'];`
- `Math.random()`は、0以上1未満のランダムな小数を作ります（例：`0.732...`）
- `Math.floor()`は、小数点以下を切り捨てて整数にします（例：`Math.floor(2.9)`は`2`になります）
- この2つを組み合わせると、配列からランダムに1つ選べます

```js
const randomIndex = Math.floor(Math.random() * omikujiResults.length);
```

- `randomIndex`は`0`から`omikujiResults.length - 1`（つまり`0`〜`2`）のどれかのランダムな整数になります
- `omikujiResults[randomIndex]`で、配列からその番号の値を取り出せます（配列の中身を順番ではなく番号を指定して取り出す書き方は、3-3では出てきませんでしたが、ここで使います）

### 確認チェック

- ボタンを押すたびに、表示される結果が変わることがある（毎回変わるとは限らないので、5〜6回押して確認する）
- 「大吉」「吉」「凶」以外の文字が表示されない

［スクショ ch03-2：おみくじボタンを何回か押した結果（結果が変わることが分かるように2〜3回分）］

### うまくいかないとき

- 毎回同じ結果しか出ない場合、`Math.random()`の掛け算の対象（配列の長さ）が正しいか確認する → `faq.md`の「おみくじがいつも同じ結果になる」を見る
- `undefined`と表示される場合、`randomIndex`が配列の範囲（`0`〜`2`）に収まっているか確認する

## 3-8 タスクの配列を画面に一覧表示する（第6章の予告）

### やること

この講座でこれから作る「かんたんタスク」というアプリでは、タスクの一覧をこのような「オブジェクトの配列」で表します。試しに、配列の中身を画面に表示してみましょう。本格的な一覧表示（1件ずつ枠で区切って、チェックボックスや削除ボタンを付ける）は第6章で作ります。ここでは「配列の中身を順番に画面に出す」練習だけを行います。

### コード

`<body>`に追加する。

```html
<p id="taskListPreview"></p>
```

`<script>`に追加する。

```js
const taskListPreview = document.getElementById('taskListPreview');

const taskList = [
  { id: 1, title: '牛乳を買う', done: false },
  { id: 2, title: '掃除をする', done: true }
];

function renderTaskListPreview() {
  let taskListText = '';
  for (const task of taskList) {
    taskListText = taskListText + task.title + '、';
  }
  taskListPreview.textContent = taskListText;
}

renderTaskListPreview();
```

### うまくいったときの結果

画面に「牛乳を買う、掃除をする、」と表示される。

［スクショ ch03-3：タスクの配列を画面に一覧表示した結果］

### うまくいかないとき

- 何も表示されない場合、`renderTaskListPreview();`（関数を呼び出す行）を書き忘れていないか確認する

## 3-9 JSONの形を見る

### やること

「JSON」は、オブジェクトを「文字として送れる形」に変えたものです。第8章で、画面とサーバーの間でデータをやり取りするときにこの形を使います。ここでは、オブジェクトとJSONの見た目の違いを確認するだけにします。

### コード

```js
const profile = {
  name: 'たろう',
  age: 20
};

console.log(profile);
console.log(JSON.stringify(profile));
```

### うまくいったときの結果

コンソールに次の2行が表示される（見た目はブラウザによって多少異なる）。

```
{name: 'たろう', age: 20}
{"name":"たろう","age":20}
```

1行目は「オブジェクト」、2行目は「JSON形式の文字列」です。2行目はキーがダブルクォート（`"`）で囲まれていて、全体が1つの文字列になっている点に注目してください。

### 確認チェック

- オブジェクトとJSON文字列の見た目の違い（キーの引用符、全体が文字列かどうか）を自分の言葉で説明できる
