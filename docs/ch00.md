# 第0章 ゴール確認：完成品を触ってみよう

## この章のゴール

これから作るアプリの完成形と、講座全体の流れをイメージします。まだ自分では何も作りません。今日は「動くものを触ってみる」だけの日です。

## 0-1 完成版アプリを操作してみる

### やること

講師が用意した、完成版の「かんたんタスク」を実際に操作してみます。タスクの追加・完了の切り替え・削除ができます。

### 操作

1. 講師から共有されたURLをブラウザで開く
2. 入力欄にタスクを入力し、追加ボタンを押す
3. 追加したタスクのチェックボックスを押し、完了状態を切り替える
4. 削除ボタンを押し、タスクを削除する

### うまくいったときの結果

タスクの追加・完了の切り替え・削除が、画面を見ながらその場でできる。

［スクショ ch00-1：完成版アプリの画面（タスクが数件入った状態）］

### うまくいかないとき

- ページが表示されない、真っ白になる場合は講師に伝える（無料プランの都合で、最初のアクセスに時間がかかることがある）

## 0-2 スマートフォンからも同じURLを開いてみる

### やること

自分（または隣の人）のスマートフォンで同じURLを開き、パソコンで見たときと同じデータが表示されるか確認します。

### 操作

1. スマートフォンのブラウザで同じURLを開く
2. パソコンで追加したタスクが、スマートフォンにも表示されているか確認する

### うまくいったときの結果

パソコンとスマートフォンで、同じタスクの一覧が見える。

### 考えてみよう

パソコンとスマートフォンは別の機械なのに、なぜ同じデータが見えるのでしょうか。「データがどこに保存されているか」を隣の人と話し合ってみてください（答えは、これから講座を通して分かっていきます）。
